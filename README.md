# Syncly — AI-Powered Real-Time Chat Application

Syncly is a full-stack chat application built using the MERN stack.
It enables users to communicate in real time and includes AI-powered
features to enhance the messaging experience.

## Overview

Syncly combines real-time messaging, user authentication, media sharing,
and AI integration in a single application. It uses Socket.IO for
real-time communication and MongoDB for data persistence.
